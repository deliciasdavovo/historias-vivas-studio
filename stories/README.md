# Biblioteca de histórias

Começa vazia em 25/11/2026. Não importar projetos antigos.

Cada nova história autorizada para publicação deve ser registrada em um arquivo JSON UTF-8 nesta pasta, com nome estável e identificador único. A central carrega os arquivos .json automaticamente ao atualizar.

Campos: `id`, `title`, `style`, `script`, `cover`, `characters` (lista com `name`, `image`, `description`), `scenes` (lista com `title`, `duration`, `prompt`, `image`), `caption`. Imagens devem ser URLs HTTPS de arquivos acessíveis ou dados de imagem suportados; nunca inventar URLs. O repositório é público; publicar somente conteúdo autorizado. Imagens locais podem ser anexadas na própria central. Não incluir segredos ou informações privadas.

## Padrão editorial vigente

Antes de cadastrar ou revisar uma história, seguir [as regras de produção e auditoria](../AGENTS.md), sincronizadas com o plugin Direção de Personagens — Mitos. Os prompts Pavo incluem narração e diálogos audíveis em português do Brasil; não gerar vídeo mudo por padrão. Histórias já publicadas permanecem intactas até revisão expressamente autorizada.
